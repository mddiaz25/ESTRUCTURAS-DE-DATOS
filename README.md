# ESTRUCTURAS-DE-DATOS

Práctica de algoritmos y estructuras de datos básicas.

## Contenido

- `Pila`: apilar, desapilar, cima, validación de vacío y tamaño.
- `TablaHash`: insertar, obtener y eliminar claves con manejo de colisiones por cubetas.
- `invertir_texto(texto)`: ejemplo de uso de pila.
- `contar_frecuencias(elementos)`: ejemplo de uso de tabla hash.
